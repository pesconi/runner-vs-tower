# Runner vs Tower (working title)

Mobile game by Jungle Degree: a crowd runs through math gates (add, subtract, multiply, divide)
and the resulting army is launched against an enemy tower. Knock the tower down to win the level.

**Status:** planning. Unity project scaffolded, no gameplay yet.
